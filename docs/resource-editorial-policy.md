# Ressourcenregeln / 资源编辑规范

Ein Eintrag beschreibt eine konkrete externe Ressource mit kurzem Zweck, Originalquelle, Kostenumfang und Zugang. Die Sammlung enthält keine eigenen Lernanleitungen.

每条资源描述一个具体外部入口，附简短用途、原站、费用范围和访问条件，不编写学习教程。

| Feld / 字段 | Regel / 规则 |
| --- | --- |
| Anbieter / 来源 | Stabile ID und klarer Name; mehrere eigenständige Angebote desselben Anbieters bleiben getrennt. / 稳定 ID 和明确名称，同机构不同用途入口分别保留。 |
| Medien / 媒体 | Webseite, PDF, Audio, Video, App, RSS, E-Book oder Buch. Themen und Funktionen gehören in separate Merkmale. / 网页、PDF、音频、视频、应用、RSS、电子书或图书，主题及功能另记。 |
| Lernniveau / 学习等级 | Offizielle Zuordnung benötigt einen Quellenbeleg. Editorische Zuordnung bleibt ausdrücklich Referenz. / 官方标级须有来源，编辑标级明确为参考。 |
| Neutrale Dienste / 等级中立服务 | Informationssuche und allgemeine Werkzeuge besitzen keine Sprachzulassung; Leseschwierigkeit kann separat angegeben werden. / 信息查询和一般工具没有语言准入条件，阅读难度可单独说明。 |
| Kosten / 费用 | Kosten des verlinkten Inhalts; kostenlose Information ist keine kostenlose Dienstleistung. Plattform- und Premiumunterschiede knapp erklären. / 标注链接内容费用，免费信息不等于服务免费，简述平台和高级功能差异。 |
| Zugang / 访问 | Tatsächliche Nutzung betrachten: lesen, herunterladen, üben oder synchronisieren. Frei lesbare Werbung ersetzt keinen Zugang zur Funktion. / 核查实际阅读、下载、练习或同步；可读宣传页不能代替功能访问。 |
| Sprachen / 语言 | Lerninhalte getrennt von Übersetzungen und Oberflächensprachen erfassen. Nur geprüfte Unterstützung angeben. / 内容语言与翻译、界面语言分开，只写核实支持。 |
| Prüfung / 核验 | Redaktionelle Faktenprüfung und technische Linkprobe haben getrennte Daten. HTTP-Sperren und Timeouts sind keine bestätigte Einstellung. / 资料核验与网络探测日期分开，访问限制及超时不代表停服。 |
| Rechte / 权利 | Links und selbst verfasste kurze Beschreibungen; fremde Materialien nicht spiegeln. / 链接与自行撰写短介绍，不镜像外部教材。 |

Jeder öffentliche Eintrag erhält einen Prüfstatus und Quellenbelege. Nicht bestätigte Angaben bleiben als solche erkennbar; ein korrekt dargestellter offener Punkt ist einem erfundenen Fakt vorzuziehen.

公开条目记录复核状态及依据，未确认内容明确标注，不用推测代替事实。
