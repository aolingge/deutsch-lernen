# 德语学习站内容与视觉升级计划

Dieser Plan ist historisch und seit 2026-10-04 durch den Auftrag für ein reines Ressourcenverzeichnis ersetzt. Aktuell gilt der [Verbesserungsplan](../superpowers/plans/2026-10-04-resource-directory-improvement.md). Die folgenden Lernwege sind keine aktuellen Produktanforderungen.

本文件为历史计划，已于 2026-10-04 被纯资源目录的需求取代。目前以[资源目录优化计划](../superpowers/plans/2026-10-04-resource-directory-improvement.md)为准。下方学习路线等内容不再属于当前产品要求。

更新时间：2026-09-30

## 目标

把现在的“德语资源目录”升级成中文学习者可以按等级开始、按技能训练、按考试准备并追踪复习的学习工作台。首页负责解释从哪里开始和下一步做什么；README 负责让 GitHub 访客在一分钟内理解项目价值、找到入口并参与改进。

## 现状盘点

- 线上目录已有 128 个资源、12 个分类、A1-C1 路线、考试专区、新闻入口和个人学习计划。
- 仓库已有大量原创路线、语法、四项技能、词汇、考试训练与赴德生活指南，主要问题是入口太像导航清单，资源卡片缺少学习动作与选择理由。
- 首页当前依赖文字标题、数字和重复卡片表达内容；缺少有解释力的学习流程图、阶段对照和明显的“今天开始”任务。
- README 列出大量文件路径，但首屏没有项目截图/视觉预览、核心工作流、覆盖范围摘要或贡献入口；英文 README 的上线状态也过期。

## 研究依据

- CEFR 行动导向教学建议以真实沟通任务组织学习者活动，因此学习路线应围绕能完成的生活、学习和考试任务，而不是只按语法目录排列：[欧洲委员会：Action-oriented approach](https://www.coe.int/en/web/common-european-framework-reference-languages/action-orientation-in-the-classroom)。
- 第二语言间隔练习元分析（48 项实验、3,411 名参与者）支持把主动回忆分散到多个学习日，并关注延迟保持：[Kim & Webb, 2022](https://onlinelibrary.wiley.com/doi/abs/10.1111/lang.12479)。
- Goethe-Institut 的 A1-C1 在线训练结合视频、音频、图片、阅读和练习，可作为多模态资源组织与分级说明的参考：[German Online Training](https://www.goethe.de/ins/de/en/kur/typ/dto.html)。

## 实施步骤

1. **重建首屏与路径图**：采用编辑式学习地图视觉方向，以真实学习材料照片建立主题信号；用 A1-C1 任务路线图展示“输入—理解—提取—输出—复习”，每个节点链接已有内容。
2. **提高首页可行动性**：提供“选等级”“选考试”“按技能练”“打开本周计划”入口；解释 B1 学习者该如何搭配系统课程、真实输入、专项训练和复盘；保留实时搜索、12 类资源、精选入口与访问量。
3. **改造 README**：首屏增加在线站点与仓库用途，说明受众、四条学习路径、资料规模与内容边界；将长文件索引归入主题导航，补足贡献、隐私与许可入口，并同步修正英文版状态。
4. **补充示范内容**：新增一份可直接照做的 B1 一周学习计划，按日给出材料类型、时长、输入动作、输出产物和复盘办法；连接现有 B1 路线与学习模板。
5. **验收并发布**：运行目录校验、类型检查、测试、构建、隐私扫描；用浏览器检查桌面/平板/手机，覆盖导航、图示链接、首页搜索、目录计数与横向溢出；更新已部署站点并回读公网结果。

## 质量标准

- 首页首屏在桌面和手机都清楚回答“我从哪里开始”；图示上的每个步骤都对应真实页面或资料。
- 每个推荐路径明确目标水平、每次投入时间、练习动作和完成标准；内容不把考试官方要求与一般学习建议混为一谈。
- 视觉资产和图表服务于德语学习主题；统计数字来自真实目录或 API，不使用装饰性假数据。
- README 不再称项目为早期脚手架，链接均指向现存文件或公网真实页面。
- 手机 390px、平板 768px、桌面 1440px 无横向溢出，核心导航与主操作可见且可键盘访问。

## 暂不纳入

- 不把学习记录上传到服务器；现有学习计划继续保存在用户浏览器。
- 不复制第三方教材、题目或付费内容；新增外部资源只记录用途、适用范围、条件与来源。
- 在线目录管理员继续 fail-closed；页面美化不会放宽任何管理 API 权限。
